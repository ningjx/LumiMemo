## 2. 性能：条件 Go（正确性全过；性能经一轮优化后仍超标，余量列为 Phase 1 待办）

### 2.1 结果

| 场景（§3.6 预算） | 预算 | 优化前 | 优化后 | 判定 |
|---|---|---|---|---|
| [A] 全量排版 10,000 字符 + 3 浮动 | < 8 ms | ~1900 ms | **75.1 ms**（P95 77.1） | 超 9.4× |
| [B] 拖动逐帧重排 3,000 字符 + 1 浮动 | < 4 ms/帧 | ~560 ms | **24.4 ms**（P95 25.6） | 超 6.1× |
| [C] Demo 拖动帧率 | ≥ 55 fps | 46 fps（超 18ms 的帧占 36%） | **143.6 fps** | **达标** |

[C] 采集口径：Demo 正文（约 480 字符）连续拖动 5.6 秒、801 帧；平均 143.6 fps、P95 帧长 10.05 ms、
最长 12.67 ms（≈79 fps）、超 18 ms 的帧 **0.0%**。平均帧率接近 144 fps 说明显示器是 ~144Hz——
每帧预算只有 6.9 ms（60Hz 是 16.7 ms），P95 10 ms 意味着约 5% 的帧未跟上 144Hz，但离验收线很远。

**口径提醒**：[C] 是**小文档**手感，[B] 的 3,000 字符才是压力口径（24.4 ms/帧 ≈ 41 fps），两者不可
互相替代。[A]/[B] 超标的余量见 §2.3。另注：平均帧率会掩盖卡顿（旧实现 46 fps 看着"只差一点"，
实际单帧 57 ms、超帧 36%），判定要看 P95 与超帧率。

### 2.2 本轮做了什么

首行探测原先用 `DrawToTextRenderer` 探基线（把整段的每个字形 run 经**托管回调**封送一遍）+
`GetCharacterRegions` 求范围。实测单次探测 **8.44 ms**，其中 `DrawToTextRenderer` 占 7.7 ms（97%），
1 万字符整段遍历达 203 ms——一次全量排版因此 1900 ms 量级。

改为读 `CanvasTextLayout.LineMetrics`：DirectWrite 建立布局时已完成断行，行度量一次读回
（`CharacterCount` / `Height` / `Baseline`，1 万字符仅 0.011 ms）。同一探测降到 **0.33 ms（25×）**。

顺带修掉一处隐患：旧行盒高度取自"字形墨迹上下缘"，与 DirectWrite 自己的基线不一致，文字在行盒内会漂；
现在行盒 = DirectWrite 行高、基线精确对齐。

### 2.3 剩余缺口的原因（已定位，未实施）

每取一行仍要对"剩余全文"重新断行一次（读 `LineMetrics` 会逼 DirectWrite 算出剩余文本的全部行），
整段合计 **O(字符数²/行高)**。解药是**按段宽批量**：一个段宽只建一次布局、一次读回该宽度下的所有行——
实测候选 `25×400 字段落整篇重排 = 7.86 ms`，正好压在预算线上（计入引擎自身行盒开销预计 8–15 ms）。

代价是把 Core 的度量接口从"问第一行"改成"一次问一批行"，并同步改引擎行循环、渲染层逐行取用与单测。
**列为 Phase 1 待办**：真实便签普遍远小于 1 万字符，当前结构在小文档上已满足体验；待真实笔记数据
证明需要时再做。

### 2.4 注意：这条路径不吃 Release 优化

`创建布局 400 字`：Debug 0.33 ms / Release 0.31 ms——成本几乎全在 WinRT 互操作，与 JIT 优化无关。
**基准对比必须用同一构建配置**，不要用"Release 会更快"去抵消预算缺口。

## 4. 过程结论（供后续参考）

1. **透明 surface 上的自绘文本若要吃指针事件，控件必须有非 null 背景**：Panel 的 null 背景只在渲染上等同透明，
   不参与命中测试——`FloatWrapView` 因此收不到任何 `PointerPressed`（拖动失效）。全透明画刷可命中且不遮毛玻璃。
2. **浮动矩形每次排版都归一化进内容框**（`FlowLayoutEngine.PlaceFloats`）：窗口收窄时把溢出的浮动拉回，
   只作用本次排版、不改作者位置，故窗口恢复宽度后浮动回到原位。
3. **性能问题的定位方式是分量计时，不是猜**：一次探针跑出 8 ms/行 的分解，直接指到 `DrawToTextRenderer`，
   避免了在 `GetCharacterRegions` 等无关项上来回试探。
