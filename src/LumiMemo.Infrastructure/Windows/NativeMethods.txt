// 为什么用 CsWin32 而不是手写 [DllImport]：手写签名的错误是这个项目最容易出、

// ---- D.5 「显示桌面」与前台事件（§13.6）----
// 这一节整体是实测的产物，加/删任何一行前请先看 WindowManager 里那段长注释。
//
// 「显示桌面」（Win+D）**不是**最小化：ShowInTaskbar=False 的窗口会被 WPF 挂上一个
// Hidden Window 当 owner，而桌面**跳过有 owner 的窗口**，所以便签从来没被最小化过
// （实测：按完 Win+D，管理器 icon=MIN，便签 icon=normal 且 IsWindowVisible 全程为真）。
// 用户看到的"消失"是便签被升到一切之上的桌面窗口盖住了，点回别的窗口桌面就降下去。
// 既然最小化根本不存在，原来那条用来还原的 ShowWindow 也就没有用处，已从 D.1 删掉。
//
// 普通 z 序够不到桌面之上（实测 SetWindowPos(HWND_TOP) 压不过，换到桌面成为前台的那
// 一刻调用也只在头两秒有效，而且还会把前台抢回便签）。唯一有效的是临时置顶。
// 于是这里需要一条告诉"桌面什么时候成为前台"的事件钩子。
//
// 它不属于下面 D.8 禁用的 SetWindowsHookEx：那一条禁的是往别人的消息流里插钩子，
// 而 EVENT_SYSTEM_FOREGROUND + WINEVENT_OUTOFCONTEXT 是订阅系统的事件通知，
// 回调走本进程的消息队列，不注入任何进程。硬要求是必须在 UI 线程上注册。
SetWinEventHook
UnhookWinEvent
EVENT_SYSTEM_FOREGROUND
WINEVENT_OUTOFCONTEXT
GetShellWindow
